## 🌍 Tentang Proyek

**Digital Twin Monitoring Tong Sampah Otomatis** adalah proyek yang dirancang untuk membantu memantau kapasitas tong sampah melalui sistem digital. Sistem ini menampilkan persentase isi tong sampah, status kapasitas, visualisasi digital twin, serta peringatan ketika tong sampah hampir penuh atau penuh.

Proyek ini dikembangkan menggunakan pendekatan **Agile dengan metode Scrum**.

## 🎯 Tujuan Proyek

- ♻️ Memantau kapasitas tong sampah secara digital.
- 📊 Menampilkan persentase isi tong sampah pada dashboard.
- 🗑️ Menampilkan visualisasi digital twin sesuai kondisi tong sampah.
- 🔔 Memberikan peringatan ketika tong sampah hampir penuh atau penuh.
- 🌱 Mendukung pengelolaan sampah yang lebih efektif.

## ✨ Fitur Utama

| Fitur | Deskripsi |
|---|---|
| 📊 Monitoring Kapasitas | Menampilkan persentase isi tong sampah. |
| 🟢 Status Tong Sampah | Menampilkan status Normal, Hampir Penuh, atau Penuh. |
| 🗑️ Digital Twin | Menampilkan visualisasi digital tong sampah. |
| 🔔 Notifikasi | Memberikan peringatan ketika kapasitas mencapai batas yang ditentukan. |
| 🕒 Waktu Pembaruan | Menampilkan waktu terakhir data diperbarui. |
| ⚙️ Pengaturan Admin | Mengatur data tong sampah dan batas kapasitas. |

## 🛠️ Teknologi

Teknologi yang digunakan atau direncanakan dalam pengembangan proyek:

- 💻 **Frontend:** disesuaikan dengan implementasi proyek.
- ⚙️ **Backend:** disesuaikan dengan implementasi proyek.
- 📡 **Sensor:** sensor pengukur tingkat kepenuhan tong sampah.
- 🎨 **UI/UX:** Figma.
- 🗂️ **Version Control:** Git dan GitHub.
- 📋 **Metode Pengembangan:** Agile / Scrum.

## 🔄 Cara Kerja Sistem

1. Sensor membaca tingkat kepenuhan tong sampah.
2. Data kapasitas dikirim ke sistem monitoring.
3. Dashboard menampilkan persentase dan status tong sampah.
4. Visualisasi digital twin menyesuaikan kondisi tong sampah.
5. Sistem memberikan peringatan apabila kapasitas mencapai ambang batas penuh.
