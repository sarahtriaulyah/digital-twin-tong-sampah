# 🗑️ Digital Twin Monitoring Tong Sampah Otomatis

**Sistem Monitoring Tong Sampah Berbasis Digital Twin dengan Fitur Peringatan Penuh**

## 🌐 Tentang Proyek

Proyek ini merupakan sistem pemantauan tong sampah menggunakan konsep **Digital Twin** untuk menampilkan kondisi dan tingkat kepenuhan tong sampah secara digital. Sistem dirancang untuk membantu petugas mengetahui kondisi tong sampah dan memberikan peringatan ketika tong sampah mencapai batas penuh.

## ✨ Fitur Utama

- 📡 **Real-Time Monitoring** — Memantau tingkat kepenuhan tong sampah.
- 🔔 **Peringatan Penuh** — Memberikan notifikasi ketika tong sampah penuh.
- 🧊 **Digital Twin 3D** — Visualisasi digital dari kondisi tong sampah.
- 📊 **Data Monitoring** — Menampilkan status dan riwayat pemantauan.
